# NeuraTiM Moodlo — emoji styles and Feelingverse

The downloadable emoji styles and Feelingverse stories of NeuraTiM
Moodlo (https://moodlo.neuratim.com). `catalogue.json` lists the styles
and `previews/` shows them; `feelingverse/catalogue.json` lists the
stories; `worlds/catalogue.json` lists the mood worlds to download. The
styles, stories and worlds themselves are in `files/` and open in the
app, which downloads them only when asked.
